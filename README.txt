ПОРТФОЛИО КАРИНЫ ЛАПЕНКО — GITHUB PAGES

Структура:
src/ — редактируемые страницы, стили и JavaScript.
data/projects.json — галерея проектов; data/screens.json — экраны Takely.
assets/ — фото, шрифт, макеты и PDF для сайта.
resume/ — исходник Typst, локальные шрифты, фото и PDF.
scripts/build.mjs — сборка готового сайта в dist/.
.github/workflows/pages.yml — автоматическая публикация GitHub Pages.

Локальная сборка (Node.js 24; npm install не нужен):
node scripts/build.mjs
python3 -m http.server 4173 --directory dist --bind 127.0.0.1

После изменения файлов в основной ветке main GitHub Actions пересобирает и публикует сайт. Статус публикации — вкладка Actions. Сборка не меняет уже опубликованный сайт до успешной публикации новой версии.

Включение Pages: Settings → Pages → Source → GitHub Actions.

Резюме:
cd resume
typst compile --font-path fonts karina-lapenko.typ karina-lapenko.pdf
Затем скопировать PDF в assets/karina-lapenko.pdf и выполнить node scripts/build.mjs из корня проекта.

Добавить кейс: скопировать запись в data/projects.json и создать HTML-страницу в src/. Шаблон сборки уже добавляет общий контактный блок и навигацию.
Takely: в верхней части кейса показана мобильная HQ-анимация в iPhone, в масштабе 75%. При ширине от 1100 px рядом показан десктопный экран корзины; на меньших экранах в этом блоке остаётся только телефон. Ниже — галерея карточки товара, корзины, личного кабинета и UI-kit в две колонки с названиями и краткими описаниями функций. Два экрана сотрудника раскрываются кнопкой «Экраны сотрудника» и также показаны в две колонки с описаниями. Макеты доступны через увеличение и Figma; ссылки на фреймы записаны в data/screens.json.

Откат через Git (без удаления истории):
git log --oneline
git revert <SHA_коммита>
git push origin main
После успешной публикации этой версии проверить адрес сайта. Предыдущая история остаётся доступной в репозитории.

Мобильная анимация Takely:
assets/takely-motion/ — прозрачный HQ-плеер (1272 × 2634, Figma 3×, цикл 36 секунд, скорость 1,5×).
Встроена в верхнюю часть src/takely.html на месте обложки. Размер на странице уменьшен до 75%, качество плеера сохранено. visibility.js запускает её только при видимости от 70% самого телефона, с учётом закреплённой шапки; ниже порога и в неактивной вкладке ставит на паузу. Возвращение продолжает с того же места. Нажатие на телефон/пробел — ручная пауза. Учитывается настройка уменьшенного движения. Плеер работает через Canvas, поэтому фон прозрачен без зависимости от видеокодеков. Canvas точно вписан во внутреннее окно; прокрутки внутри телефона нет. Начальный постер и iframe загружаются отложенно. Рамка iPhone — MIT (LICENSE-iphone.txt).
