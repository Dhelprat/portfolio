РЕЗЮМЕ КАРИНЫ ЛАПЕНКО

karina-lapenko.pdf — готовое одностраничное резюме.
karina-lapenko.typ — редактируемый исходник Typst.
assets/karina.jpg — исходная фотография.
fonts/InterVariable.ttf и лицензия — локальный шрифт Inter.

Компиляция из этой папки с Typst 0.15.1:
typst compile --font-path fonts karina-lapenko.typ karina-lapenko.pdf

В Typst Web нужно загрузить исходник, папки assets и fonts. Для локальной компиляции используется параметр --font-path.
Ссылки в PDF кликабельны; текст доступен для поиска и копирования.
Указаны дизайн и сопровождение Takely в течение шестимесячного проекта, без приписывания фронтенд-разработки этого продукта. Опыт фронтенда отнесён к учебным проектам.
